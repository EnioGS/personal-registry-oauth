Política de Privacidade — Personal-registry

Vigente desde 20 de novembro de 2026.

Quem usa

O Personal-registry é usado apenas pelo seu autor, com a própria conta Google. Não há outros usuários.

Dados acessados

Com a permissão gmail.readonly, o app lê metadados e conteúdo dos e-mails da conta do autor. Não envia, altera nem apaga e-mails.

Uso e armazenamento

Os dados são gravados em um banco de dados local, no computador do autor, para organização pessoal. Não são vendidos, compartilhados nem usados para publicidade.

Trechos de e-mails podem ser enviados a um provedor de inteligência artificial contratado pelo autor, apenas para classificar as mensagens do próprio autor.

O uso de informações recebidas das APIs do Google segue a Google API Services User Data Policy, incluindo os requisitos de uso limitado (Limited Use).

Revogação e exclusão

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions. Os dados locais podem ser apagados pelo autor quando quiser.
